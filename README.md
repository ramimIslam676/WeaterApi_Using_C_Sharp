# 🌤️ C# Weather App

A simple weather application built with **C#** using the **OpenWeather API**.

## ✨ Features

- 🌡️ Shows current temperature
- 💧 Shows humidity
- 💨 Shows wind speed
- ☁️ Shows weather conditions
- 🔍 Search weather by city

## 🛠️ Built With

- C#
- .NET
- OpenWeather API

## 🚀 How to Run

1. Clone this repository
2. Add your OpenWeather API key available free on OpenWeather website
3. Build and run the application
